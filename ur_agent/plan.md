# UR団地リサーチ：二子玉川周辺の繁華駅と徒歩15分圏内UR物件

## 背景・目的

二子玉川駅（東急田園都市線・大井町線）を起点に、通勤圏内で商業が繁華な駅を洗い出し、各駅から徒歩15分以内のUR賃貸団地を調査する。
繁華度の基準は「大田区蒲田・川崎市JR川崎駅レベル」（大型商業施設・飲食密集・百貨店または家電量販店あり）とした。

## まとめ・考察

| 評価軸 | おすすめ駅 |
|--------|-----------|
| 二子玉川からの近さ | 溝の口（5分）、武蔵小杉（15分） |
| UR物件数の多さ | 川崎JR（3件確認） |
| 蒲田的な庶民感 | 蒲田・大井町エリア |
| 都心アクセス重視 | 品川 |

- **川崎JR**が最もUR物件数が多く、駅近（徒歩5〜7分）の物件が揃っている
- **溝の口**は二子玉川から最短5分・乗り換えなしで最も現実的な候補
- **横浜**はURの供給が少なく、徒歩15分圏内での選択肢がほぼない
- サイトの動的ロード制限により、実際にはさらに多くの物件が存在する可能性あり → URショップや現地確認を推奨

---

## 次のステップ（案）

1. 各物件の家賃・間取り・空室状況を確認（URサイトへの直接アクセスが必要）
2. 川崎JR・溝の口エリアの物件を優先的に現地確認
3. 通勤ルートの実際の乗り換え時間を再検証（特に武蔵小杉：溝の口乗換→南武線）
